I just found out my Claude Code work cost $4,548.
Before today, I had no clue.





Found out you can read the JSONL files Claude Code writes to disk and turn them into spend, prompt, and project analytics.
I pulled the code, customized it a bit, and stared at the screen.

I used to think the Pro plan solved this.
Pay the subscription. Use the tool. Move on.
Then I saw what the actual API-equivalent number was.

241 sessions.
22,731 turns.
1.9 BILLION cache-read tokens.
$4,548 if I had paid by the token.

Here's what stopped me cold.
My fresh input was 332K tokens.
My cache reads were 1.9B.
That's the same content, re-read about 5,700 times.

This is why Claude Code feels affordable.
You're paying for a sliver of what you're actually reading.

What looking at my own data revealed:

• My most expensive prompts had huge tool results
• One Bash call returning 80K tokens cost more than ten thoughtful prompts
• One project alone burned 1.74B cache reads
• Tool calls follow 80/20: Bash, Edit, Read are everything
• Cache savings dwarf the actual fresh-input bill

Then there's the Tips tab.
It surfaces exactly where you're wasting tokens.
Repeated file reads. Oversized tool results. Subagents going off the rails.
It hands you the savings, not just the bill.

Gave it a custom skin. Light mode. Header reads "Shaid's Claude Usage".
It runs locally on my machine, refreshes every 30 seconds.
100% local. No telemetry. Pure Python stdlib.

You can't optimize what you can't measure.
