Google just open-sourced a CLI that gives Claude Code access to your entire Google Workspace.





One tool. One install. Everything connected.

Drive. Gmail. Calendar. Docs. Sheets. Slides.
All accessible from your terminal through a single command-line interface.

No MCP configs. No API wrappers. No boilerplate.

I've been using Claude Code as my daily driver for months now.
The one thing that always felt clunky was Google Workspace integration.
You'd set up MCP servers, manage multiple auth flows, deal with context bloat.

This changes that completely.

The GWS CLI reads Google's own Discovery Service at runtime.
When Google adds an API endpoint, the CLI picks it up automatically.
Zero maintenance. Zero config drift.

Here's what caught my attention:

. One interface for all of Google Workspace
. JSON-first structured responses (AI agents love this)
. Auto-discovery so it stays current without updates
. 100+ built-in skills for common workflows
. Low overhead because it's just one tool, not ten

The setup is straightforward.
One npm install. A Google Cloud project. OAuth credentials.
Six steps and you're running commands like:

gws drive files list
gws gmail users messages list
gws calendar events list

But the real power is when Claude Code starts chaining these together.
Triage emails by priority. Create docs from templates. Schedule meetings from spreadsheet data.
