I told my AI agent to check on my deploy every 10 minutes.
Then I walked away from my desk.





It kept checking. For 3 days straight.
No prompts. No babysitting. No tab switching.

That's the new Loop skill in Claude Code.

I've been using Claude Code as my daily driver for months now.
Terminal, VS Code, building projects, reviewing PRs.
It's been my second brain for a while.

But this week something shifted.

I typed one sentence: "Every 10 minutes, check if the build is passing."
Claude created a cron job, started monitoring, and reported back.
I didn't touch it again.

That's not a chatbot anymore.
That's an assistant that works while you don't.

Think about what this unlocks.

You're waiting on an urgent email. Set a 5-minute loop.
You're mid-deploy and need eyes on logs. Set an hourly check.
You're in a 3-day sprint and need progress tracking. Loop handles it.

The part that surprised me most?
It runs inside your current session.
It remembers what happened in the last check.
It builds context over time instead of starting fresh every prompt.

And you don't need to learn any special syntax.
Just tell it what you want in plain English.
Or use /loop if you prefer the command.

I also realized this is different from Scheduled Tasks.
Both exist now. Both are useful. But they solve different problems.

Loop is your "help me right now" tool.
Scheduled Tasks is your "remind me every Monday" tool.

Knowing when to use which is the real unlock.
