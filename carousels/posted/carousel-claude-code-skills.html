What Is a Skill?
  • A SKILL.md file with instructions
  • Slash command to invoke it
  • Bundle scripts, templates & examples
  • Claude loads it automatically
# .claude/skills/code-reviewer/SKILL.md
---
name: code-reviewer
description: Review code for conventions
user-invocable: true
---
# Code Reviewer
- Check for TypeScript strict mode
- Flag any `any` types
- Verify test coverage > 80%
