Configure GCP Auth
Once installed, you need to set up Google Cloud authentication. Here's the manual setup (no gcloud needed).
Shaid | GenAI Architect & BuilderTurning Ideas into Reality
Step 1: Create GCP Project
  • Go to console.cloud.google.com
  • Click 'New Project'
  • Name it (e.g. 'Claude Code GWS')
  • Wait for it to spin up, then select it
Google Cloud Console
> Select Project > New Project
> Name: Claude Code GWS
Project created. Select it.
Shaid | GenAI Architect & BuilderTurning Ideas into Reality
Step 2: Enable APIs
  • Go to APIs & Services in your project
  • Enable each API you want to use:
  • Drive, Gmail, Calendar, Sheets, Docs, Slides
  • Click the enable link one at a time
APIs & Services > Library
> Search: Gmail API > Enable
> Search: Google Drive API > Enable
> Search: Google Calendar API > Enable
Repeat for Sheets, Docs, Slides
Shaid | GenAI Architect & BuilderTurning Ideas into Reality
Step 3: OAuth Consent Screen
  • Go to APIs & Services > OAuth consent screen
  • Click 'Get Started'
  • Choose Internal (your org) or External
  • If External: add your email as test user
  • Fill in app name and contact info, then create
OAuth consent screen
> App name: GWS CLI
> User type: Internal (or External + test user)
Consent screen configured
Shaid | GenAI Architect & BuilderTurning Ideas into Reality
Step 4: Create OAuth Client ID
  • Go to APIs & Services > Credentials
  • Click 'Create Credentials' > OAuth Client ID
  • Application type: Desktop app
  • Name it (e.g. 'GWS')
  • Download the JSON file
Credentials > Create Credentials
> OAuth Client ID > Desktop app
Client ID and Client Secret created
> Download JSON
Shaid | GenAI Architect & BuilderTurning Ideas into Reality
Step 5: Save Credentials & Login
  • Save the downloaded JSON to ~/.config/gws/
  • Rename it to client_secret.json
  • Run gws auth login
  • Browser opens, choose your account
  • Allow access to all services
$ mv ~/Downloads/client_secret*.json \
~/.config/gws/client_secret.json
$ gws auth login
Opening browser for authentication...
Authentication successful!
Shaid | GenAI Architect & BuilderTurning Ideas into Reality
Step 6: Verify It Works
  • Run a simple test command
  • If you get an API error, click the enable URL
  • Wait 10 seconds and retry
  • Once it works, you're all set!
$ gws drive files list \
--params '{"pageSize": 5}'
Found 5 files in your Google Drive
GWS CLI is ready to use!
