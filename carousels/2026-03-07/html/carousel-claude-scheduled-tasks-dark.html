5 Pro Tips
01
Run manually first to catch permission issues
02
Add a hook for sound notifications when tasks finish
03
Put 'notify me when done' in prompts for Slack alerts
04
Use one status file per task, not append logs
05
Deny destructive bash commands in project settings

Limitations to Know
01
Desktop app must be open (catches up if you miss runs)
02
Each run is stateless - use a status file for memory
03
Lock down destructive commands in permissions
04
Desktop only for now - terminal support coming soon
